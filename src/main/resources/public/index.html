LSM-KV Explorer

A log-structured merge-tree key-value store written in Java. Writes go to a WAL and an in-memory memtable, which flushes to immutable SSTables. Each SSTable has a sparse index and a Bloom filter, and SSTables get compacted together. Write some keys and watch the structure change.

Connecting…

Pods

Each pod runs lsm-kv as part of a Kubernetes StatefulSet. Kill one and watch Kubernetes replace it: the pod terminates, and a new pod with the same name is scheduled, starts, and passes its readiness check. Its volume is reattached, so its data survives.
