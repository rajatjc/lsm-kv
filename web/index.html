LSM-KV Explorer

A log-structured merge-tree key-value store written in Go. Writes go to a WAL and an in-memory memtable, which flushes to immutable SSTables. Each SSTable has a sparse index and a Bloom filter, and SSTables get compacted together. Write some keys and watch the structure change.
